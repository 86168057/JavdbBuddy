# JAVDB全能助手（JavdbBuddy）

> JAVDB 一站式增强浏览器扩展（Chrome MV3）：在线播放、预告片、预览图增强、Emby / Jellyfin 入库同步、磁力链聚合、免 VIP 热播/Top250/FC2PPV、全部评论、识图搜索等，即装即用。

## ✨ 功能特性

### 🎬 在线播放

- **一键在线播放**：详情页 / 列表页一键播放影片，无需下载任何视频文件
- **多源智能竞速**：自动并行解析多个视频源，谁快用谁
- **HLS 流式播放**：基于 HLS.js 的 m3u8 流式播放，支持画质切换、倍速、音量记忆
- **页内弹层播放器**：不离开当前页面，弹层内直接观看

### 🎞️ 预告片

- 详情页一键唤起官方预告片播放器
- 无原生预告片的影片自动切换在线播放通道

### 🖼️ 预览图

- **列表页悬停放大**：鼠标悬停封面即弹出高清预览长图
- **多源并行加载**：多个预览图源并行获取，加载更快
- **竖版大图模式**：支持切换竖版封面大图浏览

### 🔄 Emby / Jellyfin 同步

- 详情页 & 列表页实时显示入库状态标签（已入库 / 未入库）
- 一键跳转 Emby / Jellyfin 播放
- 批量校验状态缓存，避免重复请求

### 🧲 磁力链管理

- 详情页**双标签磁力页**（双站聚合）
- 列表页快捷按钮，一键复制磁力链
- 多站点磁力搜索标签，自动聚合结果

### 🔍 搜索与识图

- **多站点快捷搜索**：详情页一键跳转多个站点
- **以图搜图**：支持点击选择 / 拖拽 / Ctrl+V 粘贴上传，自动以图搜图识别

### 💎 免 VIP 功能

- 热播排行 / Top250 榜单 / FC2PPV 免 VIP 查看
- 相关清单免 VIP 查看
- 全部评论突破限制加载

### 🛠️ 其他增强

- **短评系统**：列表页 / 详情页快捷查看短评
- **演员栏**：详情页左侧竖排演员栏，快捷检索演员作品
- **无缝翻页**：列表页滚动自动加载下一页
- **导航增强**：导航栏集成「排行榜」快捷入口（热播 / Top250 / FC2）
- **卡片动画**：卡片悬停浮起动效，可调节卡片列数与页面宽度
- **快捷浮钮**：返回顶部 ⬆ / 翻到底部 ⬇

## 🚀 安装（Chrome / Edge）

![安装流程](docs/install.svg)

### 方式一：官网页面（推荐）

👉 访问官网页面获取最新版本、功能介绍与安装说明：[JAVDB全能助手 — 官网页面](https://www.dmdx.cc/javdbbuddy)

### 方式二：手动加载

1. 下载扩展安装包（ZIP），解压到一个**固定目录**（解压后不要删除或移动该文件夹）
2. 打开 Chrome，地址栏输入 `chrome://extensions` 回车，进入扩展管理页
3. 打开右上角的**「开发者模式」**开关
4. 点击左上角**「加载已解压的扩展程序」**，选择刚解压出的文件夹
5. 点击浏览器右上角拼图图标，把「JAVDB全能助手」**固定到工具栏**

> 提示：扩展更新后，请在扩展管理页点击对应扩展的「重新加载」按钮，并刷新正在使用的网页。

## ⚙️ 配置

安装后点击工具栏扩展图标打开弹窗，登录账号即可使用。页面右上角「⚙️ 设置」按钮可进入设置面板：

- **媒体服务器** — 填写服务器地址和 API Key，即可同步入库状态
- **预览图** — 开启/关闭列表页封面悬停放大、竖版大图模式
- **磁力链** — 配置磁力链显示和复制行为
- **搜索站点** — 自定义快捷搜索的站点列表
- **播放器** — 播放器音量、画质等播放偏好
- **通用** — 卡片列数、页面宽度、无缝翻页、卡片动画等界面偏好
